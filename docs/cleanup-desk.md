# Cleanup Desk: two boundaries, two receipts

Campaign and Horde use only the virtual drive. The optional desk is a separate session: no transfer of names into a campaign save, no cleanup required to earn Horde, and no achievement or reclaimed-space award from nominating files. Browser rehearsal uses hand-authored sample metadata. Two of its files deliberately have the same basename.

**On a working packaged Mac:** select individual files via the native picker; identify the numbered huts with the Field index; one cannon hit nominates a file. Stop shooting and enter **Review shortlist**. Only **Review in macOS…** can open the native per-file decision. The exact path is selectable and scrollable. **Keep file** is the default. A separate click on **Move to Trash** calls macOS Trash; recovery is in Finder’s Trash, not virtual undo. Other weapons, second hits and X cannot commit. Nothing permanently deletes or empties Trash.

The native broker accepts an opaque ID, not a path. In-memory selections expire on exit, re-pick, changed identity or a commit attempt. The native side checks user ownership, privileged mode bits, ancestor type and permissions, volume status, file and link status and identity. It pins a metadata-only descriptor and file-reference URL; after consent, it rechecks the identity again within an OS file coordinator. Failures do not trigger a fallback move. Packages, folders, aliases, symlinks, hardlinks, hidden, executable and cloud-managed files are excluded. The distribution has only sandbox and user-selected read/write entitlements. The separately approved local Workshop adds outgoing-network capability for WebKit startup, not new file access; its web content is restricted to bundled resources.
