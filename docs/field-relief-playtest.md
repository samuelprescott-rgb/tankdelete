## Two-strike performance gate: not passed

Both calls in the retained **system WebKit** test were trusted, separate inputs. Three fictional files were armed and then confirmed. Native backing, CSS viewport and drawing buffer were all 1920×1080. The isolated test never took focus, incurred no WebGL errors, and did not use the native Cleanup Desk. This is not equivalent to an in-package GPU benchmark.

| Maximum frame time (ms) | Strike 1 | Strike 2 |
| --- | ---: | ---: |
| Launch | 30 | 19 |
| Inbound to impact | 30 | 29 |
| Centered on impact | 30 | 40 |
| Ignition | 30 | 40 |
| Rolling fire | 27 | 30 |

The two 40 ms numbers are **the same frame**, starting 5 ms after the three-file confirmation. The cap is 33.4 ms. The remainder of the route included a 190 ms pre-click stall; a playable build is not a guarantee of stable 60 fps. [Clean final timings](../tmp/production-qa/wk-1080p-G5iOQ2/report.json), [raw browser intervals](../tmp/production-qa/wk-1080p-G5iOQ2/impact-raw.json), [previous integrated build](../tmp/production-qa/wk-1080p-etLUR4/report.json). In a mounted test using the same 1,446 sparks, streaming positions and scales lowered the first 60 frames’ dynamic pose uploads from 5,552,640 bytes to 1,388,160 bytes without reducing sparks or resolution.

An [instrumented follow-up](../tmp/production-qa/wk-shader-diagnostic-LYJtBT/report.json) also confirmed both strikes, with no new shader links. It did **not** reproduce the same post-confirmation interval: the second strike’s first 500 ms after impact peaked at 21 ms, with longer intervals at other times. As instrumentation changes timing, this is diagnostic evidence only. The clean gate remains failed; neither a shader compile nor the removal of the three file entries (825 ms later on the clean trace) explains the measured 40 ms interval.

Independent visual review preferred the retained crossing, timber hit and commander to the previous production captures. The legs read in profile, but the face still looks like a faceted portrait, and the smoke and ASCII fragments are coarser than the reference. Neither the visual review nor the timing result is AAA sign-off.
