# Ghost Signal · browser playtest 1613

This is the playable **TankDelete** build with the three smoking huts on the original river skyline. It runs on your computer. You don't need a GitHub account to run an extracted copy, or Node, Rust, Tauri, or a native game installer.

1. Extract the whole ZIP (or download and extract this playtest branch).
2. Open a terminal in the folder that contains `play.py`.
3. With Python 3 installed, run **`python3 play.py`** on macOS/Linux or **`py -3 play.py`** on Windows. If the browser doesn't open, copy the local address printed in the terminal. Keep the terminal open; Ctrl+C stops the game server. Don't open `web/index.html` directly.

**First drive:** Choose **Start Campaign**, wait for “Preparing the field…” to clear, then hold **W** to cross the bridge. **S** reverses, **A/D** turn, the mouse aims, and the left button fires. The three small huts with burning roofs are distant scenery, not targets you need to destroy. Clearing the village unlocks Horde. For an immediate Horde test, use the small **∿** at the bottom-right of the main menu.

The campaign uses fictional files. In this browser version Cleanup Desk is a rehearsal only; it cannot read or trash your real files. No sign-in, personal folder, or network connection is needed to play. Use a desktop browser with WebGL 2 and hardware acceleration; this playtest was checked at 1920×1080 in Chrome on a Mac.
