# Fixed Boot Camp strike routes

Use a fresh **ordinary Boot Camp** and the route name as the last argument to
`scripts/capture-webkit-qa.mjs`. Both clicks project one frozen world point
through the player's chase camera. The tank does not move. Shaders, geometry,
resolution and timing are production settings. No alternate training manifest
or runtime target selection is used.

| Route | World x, z | Armed then confirmed | Debris instances |
|---|---|---|---:|
| `boot-landmark` | 0, 7.971431828621334 | Historically ancient-backup.zip, camera-roll.mov, debug-session.log: 2,490 MiB | 1,446 historically |
| `boot-east-three-r7` | 25.5, 12.4 | mixdown-final.wav, screenshot-copy.png, unused-installer.dmg: 286 MiB | 1,237 (−14.45%) |
| `boot-east-four-stress-r7` | 20.7, 16.4 | Those same three plus scratch-code.ts: 290 MiB | 1,569 (+8.51%) |

The authored downstream hut relocation moved camera-roll.mov 29.22 units from
ancient-backup.zip; the strip's maximum diagonal is 20.74. Every three-file
combination as heavy as the historical one needs both files. A different camera,
rotation or seed therefore cannot restore the old result on the current layout.
The original route and meaning of its check remain available; the two eastern
routes are **not** retroactive passes on that workload.

For each eastern route both inbound and impact totals must equal its file count.
The live HUD must separately show the expected bytes armed during the first
impact, the same exact bytes freed after the second, the expected deletion score,
and a sector count reduced by precisely three/four. Count and byte sum uniquely
identify that subset of the 13 virtual files. Neither an incidental casualty nor
a four-contact toast with three files counts. The projected aim never reads actors.
Camera, focus, runtime, all frame windows, and the 33.4 ms gate remain unchanged.

Run `node scripts/check-boot-strike-routes.mjs` for the CPU-only point/footprint,
whole-pixel chase projection, exact receipts, workload, and 60-second mounted
patrol checks. These do not certify device timing or replace the two real strikes.
