# CC0 wooden supply crates

Author: Yughues / Nobiax. Source: https://opengameart.org/content/free-wooden-crates

Anonymous source archive: https://opengameart.org/sites/default/files/Free%20Wooden%20Crates.7z

The author's source page and included `readme.txt` both explicitly identify CC0 1.0. Original source files are unmodified: Crate-04.obj (case + lid, 768 triangles), diffuse.tga and normal.tga (512×512 each). Only this crate variant is shipped. The source archive/other variants remain in the ignored temporary study folder.

Runtime preparation merges the case and lid, normalizes their common bounds, and draws three static instances in one batch (2,304 triangles total). Original diffuse is sRGB; normal is non-color data with strength 0.35. Roughness0.93, metalness0. Weathered tint is a material setting, not an edited source image. No executable source from the pack is used.
