# River hut paint

The original four-panel material study was made for TankDelete with the **built-in image generation tool**, not copied from the references. `hut-sheet-v1.png` is the reduced source. The game uses `public/images/textures/ghost-hut-materials-v1.png`, a padded 768×512 atlas packed to the existing thatch, bamboo, timber, earth and tin UVs. The locally generated sky paintings have a separate source, `scripts/bake-ghost-horizon.mjs`.

To rebake the hut atlas, run `node scripts/bake-ghost-hut.cjs` from the project with `sharp` available to Node. It is an optional art-authoring dependency, not a runtime or player-install dependency.

## Generation prompt

Use case: stylized-concept. Asset type: ONE original seamless material atlas for the live Ghost Signal pixel-art 3D game. Square image split exactly into four equal square quadrants flush at the centre; each quadrant filled edge to edge by a completely different TILEABLE material, no framing, labels, borders, blank space or perspective. TOP LEFT: irregular VERY pronounced overlapping rows of weathered nipa palm thatch, torn split leaf tips, bundled with small fiber ties, sun-bleached blade edges; fibers point downward. TOP RIGHT: woven split bamboo outer wall, two-over-two-under broad ochre and celadon weave, weather stains, a few frayed strands. BOTTOM LEFT: weathered lengthwise grain of one broad tropical hardwood plank, horizontal checking and knots, split tips and worn bevels; no individual plank seams as these are in the game's mesh. BOTTOM RIGHT: faded galvalume corrugated tin with small patches of cinnamon rust, ridges vertical. Hand-placed stepped pixel clusters, 1990s arcade art, ~100 native pixels per quadrant, varied 5-8 local colors for each: golden straw, clay, olive-grey, muted ultramarine occlusion. Prioritize long identifiable shapes that read when tiny; no uniform micro-noise or strokes on every single pixel. Diffuse/albedo, soft neutral illumination, local crevice light only, no sun shadows across the panel. No buildings, terrain, UI, objects, text, or branding. Fill the entire canvas.
